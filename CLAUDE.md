## Commands

- `npm run dev` — Vite dev server on port 3000
- `npm run build` — production build; `npm run preview` — serve the build
- `npm run lint` — ESLint (`@tanstack/eslint-config`)
- `npm run check` — Prettier check; `npm run format` — Prettier write + ESLint fix
- `npm run generate-routes` — regenerate `src/routeTree.gen.ts` manually (the Vite plugin also does this during dev/build)

- `npm test` — Vitest single run; `npm run test:watch` — watch mode
- Single test: `npx vitest run src/router.test.tsx` or `npx vitest run -t "test name"`

Vitest is configured in `vitest.config.ts` (separate from `vite.config.ts` so the devtools/router plugins don't run): jsdom, globals, Testing Library + jest-dom set up in `src/test/setup.ts`, tests match `src/**/*.{test,spec}.{ts,tsx}`.

Caveats in the current checkout:
- `eslint.config.js`, `prettier.config.js` and `.prettierignore` are not present, so `lint`/`format`/`check` won't work as configured until they are restored.
- If `vite` fails with "Cannot find native binding" (`@rolldown/binding-darwin-arm64`), it's the npm optional-dependency bug: `rm -rf node_modules package-lock.json && npm install`.
- Vite 8 and jsdom need Node ≥ 20.19 / 22.12; the machine is on Node 22.

## Architecture

Client-side React 19 SPA (despite the "TanStack Start" wording in the README, only TanStack Router is installed — there is no Start/SSR server). Built with Vite 8, Tailwind CSS 4 (via `@tailwindcss/vite`), and TypeScript.

- Entry: `index.html` → `src/main.tsx` mounts `<RouterProvider>` into `#app`, using the router from `getRouter()` in `src/router.tsx`.
- Routing is file-based: files in `src/routes/` become routes. `src/routes/__root.tsx` is the root layout (renders `<Outlet />`, imports `src/styles.css`, mounts TanStack Devtools with the Router panel).
- `src/routeTree.gen.ts` is generated by the router plugin — do not edit by hand.
- `vite.config.ts` plugin order matters: `tanstackRouter` must come before `viteReact`. `autoCodeSplitting` is enabled.
- Path alias: `#/*` → `./src/*` (via `package.json` `imports`, resolved with `resolve.tsconfigPaths`).
- The router type is registered globally in `src/router.tsx` (`declare module '@tanstack/react-router'`) for type-safe links/navigation.
